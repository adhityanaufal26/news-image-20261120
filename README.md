A cream newspaper front page summing up Friday 20 November 2026 in one 1024×1024 image: Cyclone Akvan's Odisha landfall, Trump deferring the Iran decision to 2027, and the Riyadh tower strike with a mined Hormuz tanker lead 32 dated stories with a UTC timeline, region counts, the day in numbers, a world map with numbered pins, and a date-check box listing earlier stories left out on purpose. All drawings are original Pillow vector-style illustrations.

## Run it

`python3 main.py` copies `entry.png` to `/output` (set `MAKEFUN_OUTPUT_DIR` locally to choose another directory). `python3 build_image.py` redraws `entry.png` deterministically with Pillow.
